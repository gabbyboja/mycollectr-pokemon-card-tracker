# <h1><img src="assets/images/pokemonlogo.png" width="20" height="20" />PokéTrack</h1>

A Pokémon card collection tracker inspired by Collectr.

## Features

- Add purchased Pokémon cards
- Track total spending
- View total card count
- Date Started Collecting/First Purchased Card

## Tech Stack

- HTML
- CSS
- PHP
- JavaScript
- MySQL

## Installation

1. Clone the repository:
```bash
git clone https://github.com/gabbyboja/mycollectr-pokemon-card-tracker.git
```

2. Move the project into your local server folder (XAMPP htdocs)

3. Import the database using phpMyAdmin

4. Update database credentials in dbconfig.php

5. Open in browser:

http://localhost/your-project-folder
